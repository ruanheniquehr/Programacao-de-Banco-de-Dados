Este projeto consiste na criação de um banco de dados para um sistema de E-commerce utilizando MySQL, aplicando conceitos de Programação de Banco de Dados.

Foram desenvolvidas estruturas para cadastro e gerenciamento de produtos, vendas e auditoria de preços, além da implementação de recursos avançados do banco.

Funcionalidades implementadas:

Views: exibição apenas dos produtos disponíveis em estoque.
Functions: cálculo automático de desconto de 10% para compras com 3 ou mais unidades.
Triggers: registro automático de alterações de preço na tabela de auditoria.
Procedures: atualização manual do estoque com retorno de mensagem.
Materialized View (simulada): geração de resumo de vendas utilizando tabela física e procedimento de atualização.
Grant e Revoke: controle de acesso dos usuários às informações do sistema.
